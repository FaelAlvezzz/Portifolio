# Portfólio Profissional - Rafael A Serafim

Aplicação React com Vite desenvolvida para apresentar perfil profissional, stacks prioritárias e projetos com foco em posicionamento para oportunidades como Desenvolvedor Java Júnior.

## Stack do projeto

- React
- Vite
- CSS com design tokens
- Componentização para manutenção e evolução

## Estrutura atual

- `src/App.jsx`: composição principal da aplicação
- `src/components/`: seções e componentes reutilizáveis
- `src/data/portfolioData.js`: conteúdo centralizado
- `src/styles/index.css`: sistema visual e estilos globais
- `vite.config.js`: configuração para GitHub Pages

## Conteúdo do portfólio

- Apresentação profissional objetiva
- Destaque para Java, Node.js, PostgreSQL, SQL e NoSQL
- Projetos públicos e projetos em desenvolvimento
- Links diretos para contato e perfis profissionais

## Como executar

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```

## Publicação

O projeto está configurado com `base: '/Portifolio/'` para deploy no GitHub Pages.
